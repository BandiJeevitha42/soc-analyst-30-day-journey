
# SOC Analyst — 30-Day Learning Journey

## Objective
Build foundational knowledge and practical skills for a
Tier 1 Security Operations Center (SOC) Analyst role.

## Day 1: Cybersecurity Fundamentals

### Topics
- What is a SOC and what does an L1 analyst do?
- CIA triad: Confidentiality, Integrity, Availability
- Threats, vulnerabilities and risks
- SIEM, events, alerts and incident triage

### Windows Lab
Commands practised:
- `hostname`
- `whoami`
- `ipconfig`
- `Get-Date`
- `Get-Process`
- `Get-WinEvent`

### Investigation Exercise
Analysed fictional authentication logs containing
four failed logins followed by a successful login.

### Initial Finding
The pattern warrants further investigation but does not
independently prove that an account was compromised.

### Skills Developed
- Basic Windows inspection
- Security log awareness
- Evidence-based investigation
- Incident report writing

## Next Steps
Learn IP addressing, DNS, ports, TCP/UDP and
network troubleshooting.
